# Irish Payroll Calculator 2026

Local web app for calculating PAYE, USC, PRSI for up to 200 employees.

## Quick Start (Windows)
1. Double-click `run.bat`
2. Open browser to http://localhost:5000
3. Add employees or upload CSV

## Features
- Real-time editable table
- 2026 Irish tax rules (approximate rates)
- Bulk calculation
- CSV export
- Professional summary

**Disclaimer**: This is an estimation tool only. Not official software. Consult Revenue.ie or a payroll professional for compliance.

Rates based on 2026 figures (subject to change).
